# DEVNIRA two real native local nodes (development P2P only)

One combined release binary launches as two independent native Substrate OS
processes on separate local ports and storage directories. Node B receives
Node A's actual P2P PeerId. Both nodes must show bidirectional system_peers,
identical nonzero development genesis, DVN/8-decimals/SS58-190 metadata, the
known inert runtime name, and common finalized-chain hash.

This is actual local P2P, NOT separate public hosts. Without external work,
finalized height may remain 0, which proves NO mined blocks. No GPU,
mining shares, confirmed rewards, signed Send, authenticated on-chain ZK V2,
independent treasury Genesis, global wallet or audited public network is
demonstrated. All absent production evidence remains blocked.
